Ensine sua LLM a criar projetos para o Estúdio SVG.

A skill contém instruções acionáveis, referência do schema JSON real, exemplos completos e regras de validação. Versão da skill: 1.0.0. Contrato do Estúdio: 3.0.0-alpha.4. Os dois números evoluem de modo independente.

Ler SKILL.md (atual)Fixar versão 1.0.0

Como usar

Em uma LLM capaz de abrir URLs, forneça o link abaixo e solicite: “Leia a skill e os arquivos de referência; gere um projeto JSON válido para o Estúdio SVG, com o tema, duração e público que informarei.”

https://rogerioduarte.org/projetos/estudio-svg/skill/SKILL.md

O link sozinho não instala plugins nem concede acesso ao computador. Para ferramentas sem navegação, baixe o arquivo Markdown ou o pacote do repositório e envie como anexo.
