# Histórico da skill Estúdio SVG

## 1.0.0 — 2026-11-13

Publicação inicial do contrato para LLMs sobre V3 Alpha 4. Inclui schema original, referências, geração guiada, exemplos de SVG e espacial, checklist de qualidade e links imutáveis.

Para publicar nova versão, crie `vX.Y.Z/` sem modificar `v1.0.0/`, valide os novos recursos e atualize os aliases `SKILL.md`, `latest.json` e `versions.json` em commit próprio.
